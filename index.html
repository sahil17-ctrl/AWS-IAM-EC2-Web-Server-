AWS IAM & EC2
Web Server

A practical learning project covering AWS identity and access management, Linux compute, network access controls, and static website hosting with Apache HTTP Server.

AWS IAMAmazon EC2LinuxApacheHTML/CSS

01 · Identity & Access

IAM users, groups, roles, and policies help control who can access AWS resources and which actions they can perform. Follow least privilege.

02 · Compute

Amazon EC2 provides virtual servers. A Linux instance can run a web server and host static website files.

03 · Network Security

Security Groups act as virtual firewalls. Allow only required traffic and restrict SSH to trusted IP addresses.

04 · Web Hosting

Apache serves HTML content to visitors. The page should be tested from a browser after deployment.

Deployment workflow

  1. Review IAM concepts and least-privilege permissions.
  2. Launch a Linux EC2 instance and protect the key pair.
  3. Configure HTTP port 80 for the demo and restrict SSH port 22 to a trusted IP.
  4. Install Apache and deploy this index.html file to its document root.
  5. Verify the website in a browser and document genuine screenshots.
  6. Stop or terminate resources that are no longer needed.

Project status: This is a prepared project package. The AWS instance and live website must be deployed and verified in the learner's AWS account before being described as live or completed.
